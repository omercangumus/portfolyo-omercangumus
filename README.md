# Ömer Can Gümüş — Portfolio

A bilingual, dependency-free portfolio for MLOps, AIOps, DevOps and cloud infrastructure work.

- `index.html`: content, metadata and semantic page structure
- `styles.css`: responsive styles and bundled fonts
- `app.js`: language preference, project filters, native dialogs and navigation
- `assets/`: local fonts, CV and sharing assets
- `OmerCanGumus.pdf`: preserved public CV URL
- `vercel.json`: existing static hosting configuration and security headers

The redesign retains legacy `#work`, `#focus`, `#background`, PDF and `cv.html` routes. Existing unused assets remain for the separate CV page. Language links support `?lang=en` and `?lang=tr`; preferences are saved locally. Project diagrams are illustrative. Open-source links and UI concept links are explicitly identified.

No build step or package installation is required. Vercel serves the repository root. All fonts and downloadable files are local.
