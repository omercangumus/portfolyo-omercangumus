02

Açık kaynak · MLOps / anomali tespiti

Cosmic Pipeline

Radyasyon kaynaklı uydu telemetrisi bozulmalarını kural, istatistik ve ML/DL katmanlarıyla tespit edip yalnızca işaretli noktaları onaran açık kaynak pipeline.

  1. 01Telemetri + detrend
  2. 02Katmanlı tespit
  3. 03Ensemble kararı
  4. 04Onarım + doğrulama
Problem

Veri boşluğu, ani sıçrama, sensör donması ve veri kayması (drift) gibi farklı bozulma türleri tek yöntemle güvenilir biçimde yakalanamıyor.

Yaklaşım

Deterministik kontrolleri Z-score, kayan pencere, Isolation Forest ve LSTM Autoencoder ile katmanlı bir akışta birleştiriyor.

Python / NumPy / SciPy / scikit-learn / PyTorch / Docker / CI
